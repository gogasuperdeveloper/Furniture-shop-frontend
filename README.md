# FurniGoga Frontend

Фронтенд для інтернет-магазину меблів FurniGoga.

## Як запустити проєкт

### Вимоги
- Python 3.12+
- Запущений бекенд на `http://127.0.0.1:8000`

### Запуск

```bash
py -m http.server 3000
```

Відкрий у браузері: `http://localhost:3000`

### Адреси

| Сервіс | Адреса |
|--------|--------|
| Фронтенд | http://localhost:3000 |
| Бекенд API | http://127.0.0.1:8000/api/v1 |
